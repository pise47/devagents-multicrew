# 目标
实现一个基于浏览器的番茄钟（Pomodoro Timer）单页应用。核心功能为提供一个25分钟的倒计时计时器，具备基础的开始、暂停和重置控制，并在计时结束时给予用户明确的提示。

## 功能
- 显示一个初始为25:00的倒计时器。
- 提供“开始”按钮，用于启动或恢复倒计时。
- 提供“暂停”按钮，用于暂停正在进行的倒计时。
- 提供“重置”按钮，用于将计时器恢复到初始的25:00状态并停止计时。
- 当倒计时归零时，通过浏览器原生 `alert` 弹窗告知用户“时间结束！”。
- 在页面标题中显示当前倒计时状态（例如：“(25:00) 番茄钟”），以便用户在浏览器标签页中快速查看。

## 验收标准
1.  页面加载后，计时器显示为“25:00”。
2.  点击“开始”按钮后，计时器每秒递减，显示正确的倒计时格式（MM:SS）。
3.  计时器运行期间，点击“暂停”按钮后，计时停止，时间保持不变。
4.  在暂停或运行状态点击“重置”按钮，计时器立即恢复为“25:00”并停止。
5.  倒计时至00:00时，页面弹出浏览器原生的 `alert` 对话框，内容为“时间结束！”。
6.  当倒计时状态改变（运行/暂停/重置）时，页面标题栏同步显示当前剩余时间。
7.  应用为单个HTML文件，无外部依赖，可直接在现代浏览器中打开并运行。

## 文件布局
- 项目类型：单页前端（纯 HTML/CSS/JS，无构建步骤）。
- 产出文件：一个 `index.html` 文件。所有样式（CSS）和交互逻辑（JS）均内联在此文件中。
