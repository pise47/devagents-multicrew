# 目标
开发一个 Python 命令行待办事项管理应用，支持添加、列出和标记完成，并将数据持久化到 JSON 文件，使用纯标准库实现。

## 功能
- 通过 `add` 子命令添加新的待办事项，指定描述文本。
- 通过 `list` 子命令列出所有待办事项，显示 ID、描述和完成状态。
- 通过 `done` 子命令指定待办事项 ID 来标记其为完成。
- 待办事项数据以 JSON 格式持久化存储在文件中，并在应用启动时自动加载。
- 整个应用仅依赖 Python 标准库，无第三方依赖。

## 验收标准
- 添加待办事项后，运行列表命令应能看到该事项。
- 列出待办事项时，应正确显示每个事项的 ID、描述和完成状态。
- 标记一个待办事项为完成后，其状态在列表中应更新为已完成。
- 应用退出后，应生成或更新一个 JSON 文件包含所有待办事项。
- 重新启动应用后，从 JSON 文件加载数据，列表应显示之前的待办事项。
- 所有功能实现不导入任何第三方 Python 包。

## 文件布局
- 项目类型：Python 项目。
- 主要产出文件：一个名为 `todo.py` 的 Python 脚本，包含命令行接口和业务逻辑。
- 数据文件：一个名为 `todos.json` 的 JSON 文件，由应用自动管理，存储待办事项数据。
- 应用直接通过 `python todo.py` 运行，无构建步骤。
