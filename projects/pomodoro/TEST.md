# 冒烟测试设计说明 — 番茄钟单页应用

## 测试策略
本项目为单页前端（纯 HTML/CSS/JS），按 PLAN.md 指定采用 smoke.json 冒烟契约。runner 启动本地服务器后 GET 指定 URL，逐一断言 expect_text 列表中的字符串出现在页面源码中。

## 覆盖的验收标准

| 序号 | 验收标准 | 对应 expect_text | 说明 |
|------|----------|-----------------|------|
| 1 | 页面加载后计时器显示"25:00" | "25:00" | 检查初始显示文本及 HTML 元素中包含该初始值 |
| 2 | 点击"开始"按钮启动倒计时 | "开始" | 检查开始按钮存在且文案正确 |
| 3 | 点击"暂停"按钮暂停倒计时 | "暂停" | 检查暂停按钮存在且文案正确 |
| 4 | 点击"重置"按钮恢复25:00 | "重置" | 检查重置按钮存在且文案正确 |
| 5 | 倒计时归零弹出 alert"时间结束！" | "时间结束！" | 检查 JS 源码中包含该 alert 文案 |
| 6 | 页面标题同步显示倒计时状态 | "番茄钟" | 检查标题含"番茄钟"关键字 |
| 7 | 单HTML文件无外部依赖 | URL "/" 可直接访问 | runner 通过本地服务器访问即可验证 |

## 额外检查项
- **DOM 元素 ID**：验证 timer-display、start-btn、pause-btn、reset-btn 四个关键 ID 存在于页面中，确保 JS 能正确绑定事件。

## 冒烟测试局限性
- 冒烟测试仅验证页面静态内容和结构，**无法覆盖动态交互行为**（如点击按钮后倒计时是否真正递减、暂停/重置逻辑、alert 弹窗触发、标题栏实时同步等）。
- 以下高风险行为未被冒烟覆盖，建议后续引入 E2E 测试或手动验证：
  1. 倒计时每秒递减的准确性
  2. 暂停后时间保持不变
  3. 重置后恢复到 25:00 并停止
  4. 00:00 时 alert 弹出且内容正确
  5. 标题栏随倒计时实时更新（如"（24:59）番茄钟"）
  6. 重复点击开始按钮不会创建多个 setInterval
